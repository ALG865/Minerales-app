# Minerales estratégicos — app Android (prueba)

App de prueba de la exposición de minerales estratégicos y críticos (CSIC).
Esta versión solo lleva las fotos de la fluorita y la calcopirita.

- La web está en `www/index.html`.
- Cada vez que se sube un cambio, GitHub genera el APK solo (pestaña **Actions** → «Generar APK» → apartado *Artifacts*).
